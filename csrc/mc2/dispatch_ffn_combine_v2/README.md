# dispatch_ffn_combine_v2

## Scope

This directory contains a standalone multi-rank executable version of the int8 `dispatch_ffn_combine` path.

Validated v1 scope:
- world size: 2
- shapes: `m=16`, `k=128`, `n=128`, `topk=2`, `expert_per_rank=2`
- data path: deterministic zero-output case generated by `scripts/gen_data.py`
- dependencies removed: `torch`, `vllm`, `.run` packaging
- dependencies retained: ACL runtime, HCCL, AscendC, catlass

## Build and run

```bash
cd /home/ntlab/zy/code/zhangyuan/vllm-ascend/csrc/mc2/dispatch_ffn_combine_v2
bash run.sh --soc ascend910_93 --world-size 2 --m 16 --k 128 --n 128 --topk 2 --experts 2 --max-output-size 32
```

## Expected outputs

- `out/output_rank0.bin`
- `out/output_rank1.bin`
- `PASS rank=0`
- `PASS rank=1`

## Known limits

- v1 validates only the int8 main path (`tilingKey = 1000010`)
- v1 does not support `bf16` or `w4_a8`
- v1 data generation is intentionally narrow and does not yet generate packed non-zero weight layouts
